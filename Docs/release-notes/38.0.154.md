# WaifuX 38.0.154 更新说明

## 新增功能

- ✨ feat(后台Helper): 壁纸渲染、调度、锁屏镜像与屏保交 Helper 常驻进程，主程序退出后桌面照常播放
- ✨ feat(guide): 新增 GuideKit 功能导览，聚光灯遮罩覆盖首页、探索、番剧、我的库与详情页，顶栏「?」随时重播
- ✨ feat(anime): 新增番剧下载缓存引擎，播放器右栏「本地」tab 播放已缓存剧集，库网格显示「N 集已缓存」
- ✨ feat(渲染组件): 渲染器组件支持独立热更新，设置页可直接检查并安装 scene/web/video 更新，免整包升级
- ✨ feat(menu-bar): 菜单栏快速切换弹窗支持每屏控制，可暂停继续、切换上下一张并调节音量与速度
- ✨ feat(scene): 新增 Scene 安全交接协议，切换前先用精确过渡图盖住桌面，新场景首帧落地后才淡出
- ✨ feat(动态桌面): 动态壁纸数据源迁移到新 CDN，封面改本地抽帧生成，上架顺序按数组位置确定
- ✨ feat(壁纸扩展): 裁剪几何改 viewport layer 裁切并重排 XPC 路由，多屏裁剪不再互相干扰
- ✨ feat(我的库): 新增库封面后台预热与全量日志导出，导出合并 App、扩展、退出诊断与 Web daemon
- ✨ feat(电池暂停): 低电量自动暂停改由壁纸扩展自主判定，电源切换瞬间不在线也能自愈
- ✨ feat(cache-janitor): 系统壁纸缓存清理改由主 App 执行，设置页新增完全磁盘访问权限检测与跳转
- ⚡ perf(ExploreGrid): 拖拽网格改为松手且未拖动才选中，大库 hover 不再每帧遍历全部布局属性
- 🔧 build(packaging): 发布包按 arm64 / x86_64 拆分，发版 CI 改 matrix 并行打包并保留 universal 全量包
- 🔧 build(推送): 手机推送工具补 x86_64 版并按包架构换装，Intel 机器也能推送到手机
- 🔒 security(网络): 本地套接字加属主校验，进程归属改按 pid、出生时间与可执行路径联合判定
